# 📂 파일 자동 분류기 (File Sorter)

지정한 폴더 안의 파일을 확장자 기준으로 자동 분류하는 CLI 프로그램입니다.

---

## 실행 환경

- Python 3.14.5
- 외부 라이브러리 없음

---

## 파일 구조

```
01/
├── sorter.py        # 메인 실행 파일
├── classifier.py    # 확장자 → 카테고리 분류 로직
├── utils.py         # 파일 이동 및 출력 유틸 함수
└── README.md
```

---

## 사용법

### 기본 실행 (현재 sorter.py 가 있는 폴더 정리)
```bash
python3 sorter.py
```

### 폴더 지정 (실제로 파일이 이동)
```bash
python3 sorter.py --path ~/Downloads
```

### 미리보기 (실제 이동 없이 결과 확인)
```bash
python3 sorter.py --path ~/Downloads --dry-run
```

## 코드 설명
 
### `sorter.py` — 메인 실행 파일
`argparse`로 `--path`, `--dry-run` 옵션을 받아서 전체 흐름을 제어합니다.
시스템 보호 경로(`/Applications`, `/System` 등)는 차단하여 실수로 중요한 폴더를 건드리지 않도록 막았습니다.
 
### `classifier.py` — 확장자 분류 로직
확장자와 카테고리를 매핑하는 딕셔너리(`EXTENSION_MAP`)와 `get_category()` 함수를 가집니다.
파일명을 받아 어느 폴더에 넣을지 카테고리명을 반환합니다. 매핑에 없는 확장자는 `기타`로 분류합니다.
 
### `utils.py` — 공통 유틸 함수
- `get_files()` : 폴더에서 파일 목록을 읽어옵니다. 숨김 파일(`.`으로 시작)은 자동으로 제외합니다.
- `move_file()` : `shutil.move()`로 파일을 이동합니다. 같은 이름의 파일이 있으면 `_1`, `_2` 를 붙여 덮어쓰기를 방지합니다.
- `print_preview()` : `--dry-run` 모드에서 정리 결과를 미리 출력합니다.
- `print_summary()` : 실제 이동 완료 후 카테고리별 결과를 요약 출력합니다.

## 회고

### 주제 선정 이유 및 앞으로의 방향
평소 파일을 정리하지 않다보면 여러가지가 섞여 이후에 필요한 파일을 찾을 때 불편햇던 경험이 있습니다.
카테부를 하며 여러 자료를 받을 것이고, 많은 새로운 파일이 생길 것 같아 이 주제를 선정했습니다.
이후 부트캠프에서 배울 LLM 기술을 접목하여, 확장자 뿐만 아니라 파일 내용이나 자연어로 파일을 분리/검색 할 수 있도록 발전시키고 싶습니다.

### 어려웠던 점
처음 맥북을 사용해보니 조작법, 단축키 등 윈도우와 다른 점이 많아 낯설었습니다. 그리고, 파이썬을 이용해서 실제 동작하는 프로그램을 만든 경험이 적어 AI의 도움을 받았습니다. CMD와 파이썬 코드를 잘 구현할 수 있게 많은 연습이 필요하다 느꼈습니다.
