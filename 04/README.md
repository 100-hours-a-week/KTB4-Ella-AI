# 4주차 과제 회고

## 배운 것 정리
이번 주차에는 머신러닝과 딥러닝의 기초 관련 개념들을 배웠다

- **데이터셋 분할**: `train_test_split`을 두 번 사용해 학습/검증/테스트 세 개로 나누는 방법과 `random_state`로 재현성을 확보하는 이유를 알게 되었다.
- **K-NN**: 거리 기반 알고리즘에서 `StandardScaler`가 필수인 이유, `fit_transform`과 `transform`을 다르게 써야 하는 이유를 배웠다.
- **4가지 알고리즘 비교**: Perceptron, SVM, Random Forest, Naive Bayes가 각각 어떤 원리로 분류하는지 이해하고, 동일한 데이터로 비교하는 것이 왜 중요한지 알게 되었다.
- **Data Augmentation**: 노이즈 추가로 훈련 데이터를 증강하는 방법과, 증강은 반드시 훈련 데이터에만 적용해야 한다는 원칙을 배웠다.
- **활성화 함수**: Sigmoid, Tanh, ReLU를 직접 정의하고 `np.linspace`로 입력 범위를 만들어 그래프로 시각화했다.
- **MLP**: 비선형 데이터에 다층 퍼셉트론을 적용해 보았고, `binary_crossentropy`와 `sigmoid` 출력층의 조합을 구현해보았다.
- **CNN**: Conv2D, MaxPooling2D, Flatten, Dense 레이어가 각각 어떤 역할을 하는지, 데이터가 층을 지나며 어떻게 변하는지에 대한 흐름을 알았다.

## 느낀점

이번 과제에서 가장 신경 쓴 부분은 **코드를 제출하기 전에 한 줄 한 줄 모두 설명할 수 있는 상태로 만드는 것**이었다.
단순히 코드를 돌려서 결과를 내는 것이 아니라, AI와 함께 코드 리뷰를 진행하며 각 코드가 왜 필요한지, 어떤 역할을 하는지를 직접 생각하고 스스로 씹어삼켜보는 과정을 거쳤다. 이해가 가지않으면 다음 문제로 넘어가지 않았다.

시간은 평소보다 훨씬 오래 걸렸지만, 내가 제출한 코드를 내가 어느정도는 잘 이해하고 있다는 생각이 들었다.
부트캠프 특성상 빠르게 진도를 나가다 보면 이해보다 완성에 집중하게 되는 경우가 많은데, 이번 주는 속도보다 이해를 택했고 그게 더 의미 있는 학습이었다고 생각한다.

- 실제 데이터도 구해서 추가적으로 실습을 해볼까 고민했었다. 근데 시간이 오래 걸릴 것 같아 이번엔 가상 데이터로만 실습했는데, 다음에는 실제 데이터셋으로도 돌려보며 정확도 차이를 하나하나 확인해보고 싶다. (귀차니즘 개선)
- 코드 리뷰를 할 때 질문을 더 적극적으로 하는 습관을 들여야겠다. 이해가 애매한 채로 넘어가는 부분이 생기지 않도록!
